# Shared vision

Identity is locked (`docs/VISION.md`). New kits still start here: world + AD before modules.

## Sequence

1. Read `docs/VISION.md` and `kits/README.md`.
2. New kit: copy the schema into `kits/<id>/`, fill world/AD first, then kit-plan.
3. Do not invent a website, engine plugin, or Field Tracing tool unless a kit step is blocked.

## Kits

The studio is kit-agnostic. Status and the in-progress kit live in `kits/README.md`. A proving-ground kit is not the house type — do not inherit its place, wear, or module language.
